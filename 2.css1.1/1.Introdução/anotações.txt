            SELETORES CSS

Class ( classes )
A classe seria como um CEP. Ela serve para identificar vários
elementos. Ou seja, vários elementos HTML podem usar a
mesma classe, e conseguimos estilizalos no CSS.

ID ( identificador único)
Ja o ID seria como seu CPF ou RG. Ele serve para identificar aper
UM elemento. Ou seja, você só pode usar um ID específico uma
ovez na sua página HTML.
